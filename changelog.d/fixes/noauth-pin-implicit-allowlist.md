- **fix(combo):** `auto/*` free candidates route through a synthetic no-auth connection id (`"noauth"`, `SYNTHETIC_NOAUTH_CONNECTION_ID`) which is not an operator-chosen pin. Since #12697 treated it as a hard implicit allowlist, every no-auth free model (e.g. `oc/muse-spark-1.2-contributor-free`) 403'd inside `auto/best-free` with "excluded by this API key's connection allowlist / quota scope" even for unrestricted keys. `implicitPinAllowlist` now treats the synthetic id as "no pin" (whole pool → no-auth path) while preserving #12697 fail-closed behavior for real credentialed combo pins; an explicit allowlist on a no-auth step is still honored.
